### 2. 首先就是证书问题

阿里太抠门了 不知道为什么 我们公司的阿里只剩下一个免费证书额度了 太bt了 还好我第一个先申请的证书是管理后台的证书 这样起码管理后台打开是https 起码面子上过的下去 没办法 只能向老板求助 老板也很抠门啊 老板甩给我一个链接 是一个github地址 彳亍 刚看了一下原来根本没给我链接 是给我打了微信语音 跟我说了四个字母 彳亍

[Acme]: https://github.com/acmesh-official/acme.sh

这个就是免费申请证书的地址了 使用方法也是很简单的 要在你域名解析到的服务器上安装 

安装在服务器上

```js
curl https://get.acme.sh | sh -s email=你自己的邮箱(这里是你自己邮箱 别把括号也复制了😊)
source ~/.bashrc
~/.acme.sh/acme.sh --set-default-ca --server letsencrypt
```

申请证书

```js
mkdir -p /var/www/acme/.well-known/acme-challenge
# 写 /etc/nginx/conf.d/(你自己的域名).conf（listen 80, root /var/www/acme）
nginx -t && nginx -s reload
~/.acme.sh/acme.sh --issue -d (你自己的域名) -w /var/www/acme --debug
```

证书的位置

```js
/root/.acme.sh/(你自己的域名)_ecc/fullchain.cer
/root/.acme.sh/(你自己的域名)_ecc/cyapi.gualele.fun.key
如果你要pem的话把.cer改成.pem就行
```

之后再要别的域名证书可以

```js
# 先保证有 listen 80 的 server_name
~/.acme.sh/acme.sh --issue -d cyadmin.gualele.fun -w /var/www/acme --debug
# 再安装到固定目录（推荐，方便续签 reload）
mkdir -p /etc/letsencrypt/live/cyadmin.gualele.fun
~/.acme.sh/acme.sh --install-cert -d cyadmin.gualele.fun \
  --key-file /etc/letsencrypt/live/cyadmin.gualele.fun/cyadmin.gualele.fun.key \
  --fullchain-file /etc/letsencrypt/live/cyadmin.gualele.fun/cyadmin.gualele.fun.pem \
  --reloadcmd "nginx -s reload"
```
